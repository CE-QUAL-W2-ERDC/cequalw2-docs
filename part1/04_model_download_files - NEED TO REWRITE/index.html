    Model Download Files¶

    PSU V4.5 Download Package¶

    All files for CE-QUAL-W2 Version 4.5 are distributed from the Portland State University (PSU) CE-QUAL-W2 website (http://www.ce.pdx.edu/w2) as a single compressed zip file. The download package is organized into directories containing source code, executables, the user manual, and example applications.

    Download Statistics

    As of 2018, model downloads from the PSU website averaged over 3 per day over the preceding 15 years. The website averaged 500--1,000 unique visitors per month.

    Directory Structure¶

    After downloading the model package, the extracted zip file contains the following directory structure:

    The following sections describe each subdirectory and its files.

    1. Examples¶

    Model application examples include:

    • DeGray Reservoir: A reservoir with a single branch and a complete water quality application
    • Spokane River: An example of a river system with multiple river sections (available with input files in both fixed-format and CSV format)
    • Columbia Slough Estuary: A fresh-water estuary example
    • Sediment Diagenesis Reservoir: A reservoir model illustrating the sediment diagenesis model of Version 4.0
    • Multiple Cascade Reservoir: A multiple cascade reservoir example
    • SYSTDG Example: A system Total Dissolved Gas (TDG) application
    • USGS Auto-Port Selection Examples: Several reservoirs that illustrate the U.S. Geological Survey (USGS) auto-port selection algorithm (introduced in Version 3.72)

    2. Excel Macro Utility¶

    An Excel macro that aids in writing CE-QUAL-W2 compatible files from within Microsoft Excel. A short user manual describing how to use the macro is included. This macro was developed by Jeffrey Gregory, Civil Engineer, U.S. Army Corps of Engineers (USACE), Nashville District.

    3. Executables¶

    The executables for the preprocessor and the model were compiled using the latest Intel Fortran compiler and are available in both 32-bit and 64-bit versions. These executables must be placed into the directories of the model input files or be used with the command-line option for setting the default directory where the model files reside. See Batch Processing and Command Line for details on the command-line option.

    4. Sediment Diagenesis Documentation¶

    Reports and documents explaining the sediment diagenesis model in Version 4.

    5. Source Code¶

    The source code for the preprocessor and model, written in Fortran 90+. The compiler settings and files necessary to compile using the Intel compiler are also included. The following compiler settings are used for the Windows application:

    Setting Description
    /O2 optimization Maximum speed optimization for most source files
    /O1 optimization Reduced optimization for init-cond.f90 and init-u-elws.f90
    Default real is double precision All floating-point variables compiled in double precision
    QuickWin Used for the preprocessor graphical interface

    The debug version is used for the released executable.

    Warning

    The subroutines init-cond.f90 and init-u-elws.f90 require the /O1 optimization level. Using /O2 on these files may produce incorrect results or runtime errors.

    Technical report for the new USGS algorithm for auto port selection.

    8. USGS Model Examples for the Auto Port Selection¶

    Four example problems using the USGS algorithm for auto port selection.

    9. W2ControlGUI¶

    The W2Control graphical user interface (GUI) was compiled using Visual Basic 6. The GUI directory also has an installation routine via setup.exe that installs the Visual Basic W2 V3.7 Model Preprocessor called W2CONTROL, which is also compatible with the V4 model.

    Once installed, the GUI preprocessor aids the model user in setting up the control file and in evaluating and changing the bathymetry of the system. This preprocessor does not automatically set up the bathymetry of the system, nor does it provide post-processing support. Significant effort is required to properly set up the model bathymetry prior to using the bathymetry editor within W2Control.

    A user manual in PDF format is included in this directory. A separate executable, W2Control, is provided in case an earlier version has already been installed. This GUI is part of the install routine for W2Tools.

    10. W2Tools Post-Processor¶

    The W2 post-processor by Dynamic Solutions-International, LLC (www.ds-international.biz). An installation routine is provided that includes both the post-processor and the W2ControlGUI. When the user selects W2L output (the old VPL output), the resulting post-processing file is used by W2Tool for all post-processing tasks, including contour plots, animations, profile plots, and time series plots.

    A brief user manual is included showing many of the features of this post-processor, as well as a directory that shows how to take field data and plot field data and model results in the post-processor. A zip file with an example from DeGray Reservoir is included, demonstrating how to include model predictions versus field data for reservoir profiles.

    11. Waterbalance Utility¶

    The Windows waterbalance utility and the more powerful updated console version of the waterbalance utility. Both are described in Part 5 of this manual. The purpose of this code is to approximate the water balance for a reservoir or lake by computing flows (positive and negative) that will allow the model predicted water level to agree with water level observations for a reservoir.

    ERDC V2026 Distribution¶

    ERDC Feature

    The Engineer Research and Development Center (ERDC) V2026 release is distributed through GitHub rather than as a single zip file download.

    The ERDC V2026 release of CE-QUAL-W2 is available from the CE-QUAL-W2 GitHub repository. The model can be obtained as pre-compiled binaries for Windows, macOS, and Linux, or compiled from source using gfortran.

    Pre-Compiled Binaries¶

    Download the latest release from the CE-QUAL-W2 GitHub Releases page.

    Platform File Notes
    Windows w2_windows_x64.zip Windows 10/11, 64-bit
    macOS (Intel) w2_macos_x64.tar.gz macOS 12+
    macOS (Apple Silicon) w2_macos_arm64.tar.gz macOS 14+, M1/M2/M3/M4
    Linux w2_linux_x64.tar.gz Ubuntu 22.04+, RHEL 8+

    Compiling from Source¶

    Prerequisites¶

    • gfortran 12 or later (part of the GNU Compiler Collection, GCC)
    • make (GNU Make)

    Install gfortran through MSYS2:

    pacman -S mingw-w64-x86_64-gcc-fortran make

    Install via Homebrew:

    brew install gcc make

    Install via your package manager:

    # Ubuntu/Debian
sudo apt install gfortran make

# RHEL/CentOS
sudo dnf install gcc-gfortran make

    Load the appropriate modules on your Department of Defense (DoD) High-Performance Computing (HPC) system:

    module load gcc
# Verify gfortran is available
gfortran --version

    Build¶

    git clone https://github.com/CE-QUAL-W2-ERDC/CE-QUAL-W2.git
cd CE-QUAL-W2
make

    The compiled executable will be located at bin/w2.

    Verifying the Installation¶

    Run the included test case to verify the installation:

    cd tests/basic
../../bin/w2

    A successful run produces output files in the test directory. Compare results against the reference outputs provided in tests/basic/reference/.
