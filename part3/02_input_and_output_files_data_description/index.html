    Input and Output Files Data Description¶

    This chapter describes all input and output files used by CE-QUAL-W2 Version 4.5. The model requires a control file and various ancillary input files for bathymetry, meteorology, boundary conditions, and initial conditions. It produces output files for snapshots, time series, profiles, contour plots, kinetic fluxes, mass/flow balances, and diagnostic information.

    All input files support two formats unless otherwise noted:

    • Fixed format (space delimited): Fields are F8.0 format (8 characters wide) with right-justified variable names on line 3. The first two lines are comments.
    • Free format (comma delimited): Indicated by a $ character as the first character on line 1. Fields are comma separated with no width restriction. The first three lines are comments/headers.

    Free Format Recommendation

    The free-format (comma-separated values, CSV) option is recommended for new applications. It removes the 8-character field width restriction and simplifies data preparation using spreadsheet software.

    Input Files¶

    Control File¶

    The control file is the primary input file for CE-QUAL-W2. It defines the computational grid, simulation time, boundary conditions, hydraulic and kinetic parameters, constituent controls, and output specifications. Two formats are supported:

    • w2_con.npt: Fixed-format text file with 8-character fields
    • w2_con.csv: Excel/CSV format with the same information organized in worksheet tabs

    CSV Control File

    When using w2_con.csv, the graph.npt file is not needed because many of its variables are included directly in the CSV control file format.

    The control file is organized into a series of "cards," each controlling a specific aspect of the simulation. The following sections describe each card and its parameters.

    The title card contains up to 11 lines of descriptive text for identifying the simulation. This information is echoed in the snapshot output file and the preprocessor output.

    TRANSPORT¶

    The [TRANSPORT] card specifies the transport solution scheme for each waterbody.

    Variable Description Options
    SLTRC Transport solution scheme ULTIMATE, QUICKEST, UPWIND
    THETA Time-weighting factor for vertical advection 0.0--1.0 
    TRANSPRT  SLTRC   THETA
       QUICKEST    0.55

    THETA Values

    THETA must be between 0.0 and 1.0. A value of 0.55 is commonly used. Setting THETA to 0.0 uses an explicit scheme (less stable), while 1.0 uses a fully implicit scheme (more diffusive).

    The [CST ACTIVE] card specifies which constituents are active for each waterbody.

    11. Refractory DOM
    12. Labile particulate organic matter (POM)

    Bathymetry File¶

    The bathymetry file defines the geometry of the computational grid. It specifies the segment lengths, layer heights, and cell widths for each waterbody. Two formats are supported: fixed format and CSV format.

    Fixed Format¶

    The fixed-format bathymetry file has 8-character fields. The file structure is:

    1. Line 1: Waterbody title
    2. Segment lengths (DLX): One value per segment (including boundary segments)
    3. Bottom elevation: One value per segment
    4. Cell widths: For each layer, the width at each segment
    Burnsville Reservoir Bathymetry file
   $Segment lengths, m
   DLX    500.0  500.0  500.0  500.0  500.0  500.0  500.0  500.0  500.0
          500.0  500.0  500.0  ...

    CSV Format¶

    When the first character is $, the file is read as CSV. The first three lines are comments/headers. Layer heights (H) and segment lengths (DLX) are explicitly labeled, followed by a matrix of cell widths organized by segment (columns) and layer (rows).

    Longitudinal Profile File¶

    The longitudinal profile file (lpr.npt or CSV) contains vertical profiles for each segment. It is used when temperature or constituent concentrations are both vertically and longitudinally stratified. Two file formats are supported: the older fixed-format version and a newer CSV version.

    1. An initial longitudinal profile is specified by setting T2I = -2.0 or initial concentration = -2.0.
    2. If temperature is included, it must be the first series of profiles.
    3. Constituent profiles must be in the same order as on the CST ICON card.

    Shade Input File¶

    The shade file provides topographic and vegetation shading data used to reduce incident solar radiation at the water surface. Shade values range from 0 (no shade) to 1 (complete shade). This file is generated by the W2 shade preprocessor program.

    Wind Sheltering Coefficient File¶

    The wind sheltering coefficient file provides time- and segment-varying wind sheltering coefficients. Values range from 0.0 (complete sheltering, no wind) to 1.0 (no sheltering).

    Light Extinction File¶

    The light extinction file allows time-varying light extinction coefficients to be specified for each segment.

    Gate File¶

    The gate file provides time-varying gate openings for dynamic gate control. This file is used when DYNGTC = ON for a gate.

    Dynamic Elevation File¶

    The dynamic elevation file provides time-varying elevations for dynamic outlet structures.

    Dynamic Pump File¶

    The dynamic pump file provides time-varying pump flow rates.

    Dynamic Pipe File¶

    The dynamic pipe file provides time-varying pipe parameters.

    Sediment Diagenesis Input File¶

    The sediment diagenesis input file (w2_diagenesis.npt) specifies parameters for the multi-layer sediment diagenesis model. This advanced model simulates the fate and transport of organic matter, nutrients, and dissolved gases within the sediment bed.

    The file is organized into several sections:

    General Parameters¶

    Variable Description Units
    HSED Thickness of the active sediment layer m
    DIFFT Porewater diffusion coefficient for temperature m² day⁻¹
    THSED Sediment temperature rate multiplier -

    Sediment Constituent Parameters¶

    The file specifies initial conditions and rate parameters for:

    • Particulate organic carbon (labile and refractory: POC_G1, POC_G2)
    • Particulate organic nitrogen (labile and refractory: PON_G1, PON_G2)
    • Particulate organic phosphorus (labile and refractory: POP_G1, POP_G2)
    • Dissolved constituents (NH₄, NO₃, PO₄, H₂S, CH₄, SO₄, Fe²⁺, Mn²⁺)

    Bubble Model Parameters¶

    When the bubble model is active, additional parameters control gas bubble formation and release from sediments.

    pH Buffering Input File¶

    The pH buffering input file specifies alkalinity buffering parameters for pH computations.

    Bed Consolidation Rate Input File¶

    The bed consolidation rate input file specifies parameters for the bed consolidation model that controls sediment layer compaction over time.

    Atmospheric Deposition Input File¶

    The atmospheric deposition input file (atm_deposition_wbX.csv) specifies wet and dry atmospheric deposition rates for each constituent for each waterbody.

    Constriction Input File¶

    The constriction input file specifies segment constrictions that reduce the effective cross-sectional area at specified locations, simulating bridges, culverts, or channel narrowing.

    Hypolimnetic Aeration Input File¶

    The hypolimnetic aeration input file specifies parameters for artificial aeration systems used to increase dissolved oxygen in the hypolimnion.

    SYSTDG Input Files¶

    The SYSTDG (System Total Dissolved Gas) input files provide parameters for computing total dissolved gas concentrations at spillways and turbines for fish passage studies.

    Graph Input File¶

    The file graph.npt is required only when using the fixed-format control file (w2_con.npt). When using the CSV control file (w2_con.csv), the graph.npt file is not needed.

    The file controls output variable formats and includes three sections:

    • Hydrodynamic variables: Format (HFMT), multiplier (HMULT), minimum/maximum for plotting
    • Constituents: Format (FMTC), concentration multiplier (CMULT), minimum/maximum for plotting
    • Derived constituents: Format (FMTCD), derived multiplier (CDMULT), minimum/maximum for plotting

    Multiplier Usage

    The concentration multiplier CMULT is a conversion factor applied to the output. Set CMULT = 1000.0 to convert from g m⁻³ to mg m⁻³ for nutrient values.

    Lake River Contour Plots Input File¶

    The lake_river_contour.csv input file specifies parameters for generating lake and river contour plots. The model senses the presence of this file and activates the feature automatically.

    The file specifies:

    • ON/OFF control
    • Number of lake contours (maximum 20) and output format (1 or 2)
    • Lake segment number, start day, and output frequency
    • Number of river contours (maximum 20) and output format
    • Branch start, branch end, start day, and output frequency

    Algae Vertical Migration Input File¶

    The w2_AlgaeMigration.csv input file describes parameters for the vertical migration model for cyanobacteria. This file is read when AVERTM is set to ON for any algal group.

    The file specifies:

    • Migration ON/OFF control
    • Number of algae groups that migrate
    • Number of migration intervals and start/end Julian days
    • Migration model selection (1: velocity time, 2: velocity time and space, 3: density growth, 4: density growth Visser)
    • Model-specific parameters including amplitude, phase shift, depth limits, and loss fractions

    Algae Toxin Input File¶

    The w2_Algae_Toxin.csv input file describes parameters for modeling algal toxin production from cyanobacteria. This file is read when any of the toxin state variables are active.

    For each toxin (microcystin, cylindrospermopsin, anatoxin-A, saxitoxin):

    Parameter Description
    CTP Fraction of algae concentration producing toxin
    CTB Ratio of intracellular toxin to dry weight biomass (mg toxin/mg DW)
    CTR Release rate (day⁻¹)
    CTD Extracellular decay rate (day⁻¹)

    Dissolved Gas Added to Turbine Input File¶

    This file provides time-varying fractions of dissolved gas added to turbine outflows. The file is named w2_spX_DO.csv for spillways or w2_gtX_DO.csv for gates.

    Field Variable Description
    JDAY Julian day
    FRAC Fraction multiplied by incoming dissolved oxygen (DO)

    A fraction of 1.0 leaves the inflow oxygen unchanged. A fraction of 1.1 increases it by 10%.

    Output Files¶

    Snapshot File¶

    The snapshot file was designed for output to a hard copy printer and contains useful information for debugging and evaluating model applications. It is a formatted text file that can be read using any text editor. It is not recommended for graphing; other output files are more suitable.

    The snapshot file is controlled by the SNP PRINT, SNP DATE, SNP FREQ, and SNP SEG cards. The file contains the following sections for each output time:

    Title Cards¶

    The title information from the control file plus the date and time of the model run.

    Time Parameters¶

    Field Description
    Gregorian date Calendar date
    Julian date Julian day and hours
    Elapsed time Days since simulation start
    Timestep Current timestep (s)
    Minimum timestep Minimum timestep to date (s)
    Average timestep Average timestep (s)
    Number of iterations Total iterations to date
    Number of violations Number of timestep violations

    Meteorological Parameters¶

    Input and calculated meteorological values including air temperature, dewpoint, wind direction, cloud cover, equilibrium temperature, surface heat exchange coefficient, and short wave radiation.

    Selective Withdrawal and Inflow/Outflow Parameters¶

    Inflows, inflow placement, temperatures, and outflows for all boundary conditions including upstream inflows, tributaries, outlet structures, and withdrawals.

    Balances¶

    Water balance, energy balance, and mass balance results for each branch and waterbody, including:

    • Spatial and temporal changes
    • Volume/energy/mass error
    • Percent error

    Balance Checks

    Volume and mass balance errors should be on the order of 10⁻⁶ to 10⁻¹³ percent. Larger errors may indicate code issues or numerical instability.

    Geometry¶

    Water surface layer number, elevation, and current upstream segments.

    Water Surface¶

    Water surface elevation and water surface deviation at snapshot segments.

    Temperature/Water Quality¶

    Temperature and constituent concentration arrays at snapshot segments.

    Time Series¶

    A time series history can be output for any number of cells in the computational grid. Output is in comma-delimited format (CSV). The model creates separate files named with a _x suffix where x = 1, 2, 3, etc., corresponding to the cells specified on the TSR SEG card.

    The time series file includes (among other variables):

    • Julian date and current time step (s)
    • Water surface elevation (m)
    • Temperature (°C) at the specified layer and segment
    • Velocity (m s⁻¹) at the specified layer and segment
    • Total flow rate through the entire segment (m³ s⁻¹)
    • Net short wave solar radiation (W m⁻²)
    • Light extinction coefficient (m⁻¹)
    • Depth from water surface to channel bottom (m)
    • Surface width (m)
    • Shade factor
    • Radiation components (net, short wave, long wave, back radiation, evaporative, conductive)
    • Reaeration coefficient (day⁻¹)
    • Active constituent concentrations
    • Derived constituent concentrations
    • Kinetic flux rates (kg day⁻¹)
    • Algal growth rate limitation fractions for P, N, and light

    Auto-Port Selection Output Files¶

    The auto-port selection routine produces two types of output:

    • Volume at specified temperatures (Volume_wbX.opt): Time series of total volume and volumes below specified temperature thresholds.
    • Outlet temperatures and elevations (wd_out.opt and str_brX.csv): Outlet temperatures, flows, and elevations for each structure.

    Fish Habitat Output Files¶

    Output files for fish habitat analysis include:

    • Fish habitat (fish_habitat.opt): Percent habitat volume and actual habitat volume for each species
    • Volume-weighted water quality parameters: At specified segments
    • Surface water quality parameters: Surface-layer values at specified segments
    • Organic matter accumulation: Bottom sediment organic matter at each segment
    • Branch/waterbody habitat files: fish_habitat_wbX.csv and fish_habitat_brX.csv

    Preprocessor¶

    The preprocessor produces three output files:

    Output (pre.opt)¶

    The pre.opt file echoes all control file inputs with descriptions, Fortran variable names, and values. It includes:

    • Time control parameters
    • Initial conditions
    • Calculation controls
    • Meteorological parameters and data statistics
    • Transport and hydraulic coefficients
    • Ice cover parameters
    • Output controls
    • Inflow/outflow information and filenames
    • Constituent parameters, rates, and stoichiometry
    • Geometric information and volume-area-elevation tables
    • Initial conditions for all segments

    Warning Messages (pre.wrn)¶

    The preprocessor generates warning messages when inputs differ from typical ranges or when potential issues are detected. Warnings do not prevent the model from running.

    Example:

    Epiphyton excretion rate [EE=0.000] < 0.001 for epiphyton group 1
Oxygen to algal respiration stoichiometry [O2AR=1.400] /= 1.1 for waterbody 1
Water surface elevation is below bottom elevation at segment 1

    Warning Messages

    The absence of warning messages does not guarantee that all inputs are correct. Not all possible input combinations can be checked.

    Error Messages (pre.err)¶

    Error messages indicate problems that will prevent the model from running correctly. All errors must be fixed before the simulation can proceed.

    Example:

    Starting time [TMSTRT=75.000] < ending time [TMEND=-320.000]
Timestep fraction [DLTF(1)=-0.850] <= 0.0
Heat exchange solution control [SLHTC= term] /= " TERM" or " ET" for waterbody 1

    Spreadsheet Profile Plot¶

    The spreadsheet profile output provides vertical profiles of temperature, constituents, and derived constituents in a comma-delimited format suitable for spreadsheet analysis. Output includes Julian day, depth, elevation, temperature, horizontal velocity, horizontal layer flow, and concentrations for each output segment.

    When SPRC is set to ONV, an additional volume-weighted output file (_volw.csv) is generated.

    Profile Plot¶

    The profile plot output file (prf.opt) was originally developed for the DISSPLA plotting package. It contains vertical profile data at specified segments and times, including:

    • Grid parameters (KMX, number of segments, dates, constituents)
    • Layer heights
    • Initial concentrations
    • Time-varying profiles of temperature and constituents

    Longitudinal Profile Plot¶

    An alternative output for the profile plot is the longitudinal profile plot. Files are named ProfLongJDXXX.csv where XXX is the Julian day. The output includes segment number, water surface elevation, flow rate, surface temperature, depth, width, volume-weighted temperature, and constituent concentrations at the surface layer.

    Vector Plot¶

    The vector plot output writes a binary file for use with the W2_POST post-processor. The file uses the w2L extension for W2 Linkage format.

    Contour Plot¶

    The contour plot output (cpl.opt) provides data for creating 2D contour plots. It includes grid geometry followed by time-varying data for all branches and waterbodies.

    When TECPLOT is ON, the output includes elevation, longitudinal distance, velocities (U, W), temperature, density, fish habitat criteria, and all active constituent concentrations in Tecplot-compatible format.

    WDO output files are not multiplied by CMULT or CDMULT, unlike the snapshot and time series output files.

    Mass Balance Output File¶

    When mass balance [MBC] is turned ON and the contour plot is active, the model outputs a summary of N and P mass balances for each waterbody in the file massbal.csv. The file includes:

    • Julian day and waterbody number
    • Total phosphorus and total nitrogen in water column (kg), sediments (kg), and plants (kg)
    • Cumulative TP and TN in outflow, tributaries, distributed tributaries, withdrawals, precipitation, and inflow (kg)
    • Cumulative sediment release and flux to sediments (kg)
    • Sediment diagenesis flux terms (kg)

    When volume balance [VBC] is ON and the contour plot is active, the model outputs a flow balance summary for each waterbody in flowbalance.csv. The file includes:

    • Julian day and waterbody number
    • Inflow volume (m³) from Qin files, precipitation, outlet structures, withdrawals, evaporation, distributed tributaries, tributaries, and ice formation/melting
    • Cumulative volumes and percent error

    • Lake_Contour_T_SegXX.csv: Lake contour for temperature at segment XX

    When withdrawal output (WDO) is specified, the model automatically writes a file for use with the W2Anim post-processor. The file is named qwo_layers_XX_wdo.csv where XX is the segment number. It contains layer-by-layer flow data for all outflows at that segment.

    Run-time Warnings¶

    The model generates run-time warning messages to the file w2.wrn. These include:

    • Water surface above grid: Water surface elevation is above the top of layer 2 at a segment.
    • Computational warning: Velocities approaching supercritical values with a negative surface layer thickness.
    • Unstable water surface elevation: The model decreases the timestep by 90% and recomputes.
    • Low water: A segment has only one active layer remaining.
    • Volume error: Volume error exceeds 1000 m³.
    • Surface layer changes: Layer addition or subtraction information.

    Instability Recovery

    When the model detects an unstable water surface elevation, it attempts recovery by decreasing the timestep. If the current timestep is less than or equal to DLTMIN, the model stops and writes an error message to w2.err. To recover, reduce DLTMAX and/or DLTF near the time of instability.
